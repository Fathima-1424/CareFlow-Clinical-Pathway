# Process Mining Activity Summary

## Objective
To understand patient journeys and identify process variations.

## Tools Used
- Python
- PM4Py
- Pandas

## Activities Performed
- Loaded the patient event log.
- Analyzed patient activities.
- Discovered patient pathways.
- Generated process maps.
- Analyzed activity frequencies.
- Identified loop-back activities.
- Studied waiting times between activities.

## Conclusion
Process Mining helps identify repeated activities, delays, and bottlenecks in patient journeys.
